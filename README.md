# Cossa’s KI: kostenloses Startpaket

Cossas-KI.zip herunterladen und vollständig entpacken.

- Mac: einmal Einrichten-Kostenlos.command, danach Start-Kostenlos.command. Homebrew wird vorausgesetzt.
- Windows: einmal Einrichten-Kostenlos.cmd, danach Start-Kostenlos.cmd. Windows App Installer (winget) wird vorausgesetzt.
- Modellgewichte werden erst bei der Einrichtung geladen. Keine API-Schlüssel oder API-Gebühren.
- Native Mac-/Windows-Installation und echte Modellleistung sind noch auf den Zielgeräten zu prüfen.
- ZIP enthält keine privaten Aufnahmen oder Zugangsdaten. Enthaltene docs/free-local.md lesen.
